# 记忆层（三层架构）

管线是**有状态的**——跨会话、可中断恢复。记忆分三层，按需加载：

| 层 | 文件 | 上限 | 作用 |
|----|------|:--:|------|
| L1 索引 | `_index.json` | 4 KB | 轻量项目索引（名字/状态/CTO 评分/下一动作）——每次启动只读这一层 |
| L2 项目 | `projects/{name}.json` | 8 KB | 单项目完整记忆：artifacts / 决策 / 审计 / 会话记录——选中项目后才加载 |
| L3 会话 | `sessions/{date}.json` | 10 KB | 归档流水（旧审查记录、快照）——写入时按需创建 |

**防膨胀是纪律**：每个文件有硬上限，超限自动裁剪/归档（裁剪前先快照到 `archive/`，可从快照恢复）。
校验工具：`python3 examples/02_memory_guard/check.py`。

**写入质量标准（4 问自检）**：① 下次恢复会用到吗？② 能从已有信息推导出来吗？③ 是不是已经写过了？④ 加上会超限吗？
写入的是「下次恢复时需要知道什么」，不是「发生了什么」。
